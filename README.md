## 🎯 About

**The Blood of Dawnwalker** is the dark fantasy action-RPG from former Witcher 3 developers. Released in **September 2026**, it became the **#1 best-selling game on Steam within 24 hours** and sold over **1 million copies in the first two days**.

Dawnwalker Utility is a **community-built companion tool** for solo players. It focuses on three things:

- **Config management** — save, load, and switch between profiles
- **Performance** — stable FPS in large open-world zones
- **Quality of life** — save backups, keybind editor, and session tools

> **Not affiliated with Rebel Wolves or Bandai Namco. Edits only local config files.**

## ❓ FAQ

<details>
<summary><b>❓ Is this an official tool?</b></summary>
<br>
No. This is a community-built utility, not affiliated with Rebel Wolves or Bandai Namco.
</details>

<details>
<summary><b>❓ Does it modify game files?</b></summary>
<br>
It edits only local config files (keybinds, graphics, HUD). It does not touch game binaries or save internals.
</details>

<details>
<summary><b>❓ Can I share my configs with friends?</b></summary>
<br>
Yes — use Export Config to save a profile to a file, then share it. Your friend can use Import Config to load it.
</details>

<details>
<summary><b>❓ Why does my antivirus flag it?</b></summary>
<br>
The utility reads and writes local config files, which antivirus software often flags as suspicious. It is safe.
</details>

<details>
<summary><b>❓ Does it work with the latest patch?</b></summary>
<br>
Yes — v1.0.0 is compatible with the September 2026 release.
</details>

<details>
<summary><b>❓ Can I revert changes?</b></summary>
<br>
Yes — every change is auto-backed up. Use Restore Backup to roll back at any time.
</details>
